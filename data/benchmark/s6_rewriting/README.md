# S6 Output-Property Control: Rewriting

This directory documents the benchmark setting for S6 rewriting experiments. The paper evaluates multiple rewriting procedures, including MPG, UTA, and Fuzzer, while preserving the underlying phishing objective.

Security-sensitive reconstructed or rewritten phishing text is not included in the public release. Public upstream resources are listed in `../../dataset_sources.csv`. Derived detector outcomes, persuasion scores, statistical tests, and paper figures are released under `results/` so the reported comparisons can be reproduced without redistributing the generated phishing text.
