# S8 Workflow Control: Generator Comparison

This directory documents the controlled generator comparison used for S8. The experiment holds the workflow and prompt set fixed while varying the LLM generator (Claude, GPT, Gemini, Llama, Mistral, and DeepSeek where reported).

Security-sensitive generated phishing text is not included in the public release. Derived detector predictions, feature measurements, statistical tests, and paper figures are released under `results/` so the generator-dependent findings can be reproduced from released analysis artifacts.
